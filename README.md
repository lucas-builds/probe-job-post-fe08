# Probe job post

A single-page website: one self-contained `index.html` (HTML and CSS, no build step), built to work on phones first and scale up to desktop.

## Run it locally

Open `index.html` in any browser.

## Deploy it yourself

Upload this folder to Vercel (or any static host). No settings needed.
